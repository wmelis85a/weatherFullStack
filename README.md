
# 🌤️ Weather Forecast App

A full-stack weather forecast application that fetches and displays weather data using a React frontend and a FastAPI backend. Powered by Python async logic, multiple weather APIs, and a touch of AI-assisted development.

---

## 🚀 Stack

**Frontend:** React + TypeScript  
**Backend:** FastAPI (Python)  
**Async:** `asyncio`, `httpx`  
**APIs Used:** OpenWeather, WeatherAPI, CPTEC INPE  
**Deployment:** Render

---

## 🧠 What I Learned

- Building a modern web backend using **FastAPI**
- Exploring **Python async** patterns and how to handle concurrent API calls efficiently  
- Structuring data using Python lists, dicts, and nested transformations
- Connecting the backend to a React frontend via async fetch logic  
- Managing React lifecycle (`useEffect`), rendering behavior, and type interfaces
- Learning faster using AI development tools (ChatGPT, Copilot, etc.)

## 📦 Running Locally

1. Clone the repository:
```bash
git clone https://github.com/wmelis85a/weather-forecast-app.git
cd weather-forecast-app
```

2. Start the backend:
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

3. Start the frontend:
```bash
cd frontend
npm install
npm run dev
```
